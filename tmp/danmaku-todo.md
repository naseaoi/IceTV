# 弹幕功能待办

## 目标

修复近期弹幕功能验证中发现的缓存恢复、映射恢复、长剧选集、集号匹配和并发改绑问题，并用回归测试与浏览器验证确认行为。

## 待办与验收标准

- [x] 服务端弹幕评论支持受控强制刷新；客户端 `forceRefresh` 必须贯穿到服务端，强刷不能继续命中旧的空结果缓存。
- [x] 只有明确的 `DANMAKU_EPISODE_NOT_FOUND` 才能清理已保存映射；`200 + 空数组` 保留映射并按“本集暂无弹幕”处理。
- [ ] 长剧候选不能被固定的全局 240 条截断；选集面板能够展示同一候选源的完整集列表，并保持响应体有界。
- [ ] 只有候选标题没有可解析集号时才允许位置兜底；存在集号缺口时不得把其他集误绑到目标集。
- [ ] 手动改绑必须以最新选择为准；旧的异步加载完成后不得覆盖新绑定的弹幕。

## 验证记录

- [ ] 每组改动先跑相关回归测试，再跑 `pnpm lint`、`pnpm typecheck`。
- [ ] 每完成一组逻辑并验证通过后提交一次，最后确认工作区和本待办状态。
