# 性能优化待办清单

目标：让用户明显感受到页面响应更快，同时降低长期运行容器的 CPU、内存和网络占用。

## 审计基线

浏览器测试环境：Next.js 开发模式、移动端 `390x844`、DPR 3、Fast 4G、CPU 4 倍降速。

- 已登录首页 LCP 约 1794ms，TTFB 约 503ms
- LCP 渲染延迟约 1290ms，占 LCP 的约 72%
- 已登录首页 DOM 约 2416 个节点，首轮创建约 36 张图片
- 未登录首页 DOM 约 1953 个节点，首轮创建约 33 张图片
- Douban 页面静止性能轨迹中，`VirtualizedGrid.readViewport` 累计触发约 488ms 强制回流
- 未登录首页已不再请求 `/api/playrecords`，但仍请求 `/api/server-config`
- Docker 健康检查每 30 秒请求完整 `/login` 页面
- 开发模式下 `/login` 响应约 178831 字符，单次请求约 2 秒

开发模式绝对值不作为生产指标。每批改动完成后，需要在现有开发环境验证功能；最终使用 production standalone 固定数据集复测。
