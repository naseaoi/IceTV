## 维护规则

- 只记录代码无法快速体现的当前约束、易误读边界与必要操作；不记录排查经过、一次性测试数字或过期结论，改动历史看 git log。
- 同一事实只在一处维护，其余用链接。部署参数以 `.env.example` 为准。
- 改动使文档中的约束失效时同次更新。
