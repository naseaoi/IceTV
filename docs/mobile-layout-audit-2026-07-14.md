## 分区页结论

分区页的加载偏差来自三个阶段使用了不同的尺寸模型：

1. 路由级骨架仍保留重构前的标题和筛选面板。
2. 数据加载骨架使用 CSS Grid 的真实子像素尺寸。
3. 数据完成后使用虚拟网格，容器宽度和行高被取整，标题区也多算了 4px。

390px 视口下，第二行卡片的加载前后纵向差从约 3.78px 降到约 0.01px。480px、640px 等断点两侧的列数、列宽和行距也已统一。

## P3：返回按钮的直达行为

该项已完成。

- 首页继续观看进入点播页后，`returnTo` 为 `/`，顶栏返回首页。
- 搜索页进入点播页后保留完整搜索参数，返回原搜索结果。
- 分区页进入点播页后保留 `type` 参数，返回原分区。
- 播放历史、收藏等入口同样记录当前来源。
- 外部直达或旧点播链接没有来源参数时回退首页。
- 分区页、直播页和收藏详情页没有来源参数时分别回退分类页或我的页面。
- 来源参数只接受站内相对路径，拒绝外部地址和 `/play` 循环路径。
- 加载阶段点击返回会终止点播初始化，后续请求不会再次覆盖当前页面。
