# 年度观看报告

## 前置依赖

历史重构与独立统计采集已完成（数据边界见 `docs/data-storage.md`「观看历史与观看统计」）。本任务只读 `playback_sessions` 与 `playback_watch_buckets`，不读也不改 `watch_history`。

## 目标

为每位用户生成指定年份的观看报告，除常规统计外，提供个性化指标。

## 已定口径

- 用户在历史里删除记录不影响年度统计：统计数据与历史分离，注销账户时一并清除。
- `measurement_version = 2` 的会话时长是实际播放的墙钟时间（倍速按真实耗时，拖动不计）；`1` 是旧的客户端估算值。两者混合汇总时界面措辞使用「约」。
- 时间维度按用户本地时区计算（请求带 IANA 时区，服务端校验，复用 `src/features/playback-stats/lib/period.ts` 的校验逻辑）。
- 连续天数按本地日历日期比较，不用毫秒差判断。
- 评价按 `created_at` 归属年份，编辑旧评价不算入当年。
- 时段、跨午夜、跨年归属用 15 分钟 UTC 对齐的时间桶（只有 v2 会话有桶）；v1 会话只能按 `started_at` 归属，报告中区分或不展示。非整小时偏移时区（如 UTC+5:45）的桶可能跨本地小时边界，按桶起点归属即可。
- 开启 `CRON_PLAYBACK_STATS_RETENTION_DAYS` 清理时，统计数据只基于现存记录，报告需提示可能不完整。

## 指标

常规：

- 全年观看时长、活跃天数、最长连续观看天数
- 月度时长分布
- Top 作品、Top 源站、观看集数
- 全年第一部 / 最后一部
- 当年评价数与平均分

个性化：

- 最活跃时间段（按本地小时的观看时长分布）、深夜观看占比与最晚一次观看
- 最投入的一天（单日时长最长）
- 偏好类型（若统计里能关联到分类信息）

不做：「今年看完 N 部」。看过时间会随状态修改被移除，会话也缺少总集数，无法可靠判定完结；改用「今年看过的作品数」。

- 注销账户后统计数据清除
