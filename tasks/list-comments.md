# 片单评论

## 目标

公开片单支持评论，配合广场、浏览量、点赞提升分享动力。

## 动手前需拍板

- 游客能否读取评论（游客可见片单的评论区是否随之公开）
- 审核方式：是否并入后台统一举报队列（现有评价举报与回复举报在 `review-social-storage.ts` 合并查询，需加第三类）
- 通知粒度：作者收到评论、评论被回复是否进消息中心
- 结构：单层平铺还是允许回复评论；独立新表，还是泛化 `video_review_replies`（后者需重构线上表，风险更高）

## 范围（按现有评价回复的约束补齐）

- 评论增删与游标分页；正文长度上限前后端共用常量；写入口校验昵称（`NICKNAME_REQUIRED`）与频率
- 举报、后台列表与管理员删除（独立后台 Guard）
- 可见性联动：片单转私密或降级时评论与举报随父片单过滤，恢复后重新可见
- 删号、SQLite 用户名大小写合并、删除片单时清理评论与举报
- 公开响应只含 `profileId`、昵称、头像种子

## 验收

- 上述约束均有存储契约测试（SQLite 与 MySQL fake）与路由测试覆盖
- `pnpm lint:strict`、`pnpm typecheck`、`pnpm test --runInBand`、`pnpm test:mysql` 通过
- 浏览器验证：登录用户评论、删除、举报；私密化后评论隐藏；游客按拍板结果可读或不可读
